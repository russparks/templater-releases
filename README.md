# GMI Templater – downloads

**[Download the latest GMI Templater app](https://raw.githubusercontent.com/russparks/templater-releases/main/GMI-Templater-App.zip)**

1. Unzip it (Windows: right-click > Extract All). 
2. Open the **GMI Templater App** folder and double-click **Open GMI Templater** (Chrome or Edge).
3. Click **Connect folder** and choose your GMI Templater folder.

The app checks this page for newer versions and shows step-by-step update instructions under **Help & updates**.
